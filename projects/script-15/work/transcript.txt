This tutorial shows you how to prepare a Canva document for later editing and explains the extra step for a fillable PDF.
Start with a document design or drag an existing PDF onto Canva's homepage and open the imported file.
Select the text you need to change.
Canva can convert supported PDF content into editable elements, but scanned pages and flattened text may remain images.
Check the conversion before rebuilding or replacing anything.
Make your changes using real text boxes, images and shapes.
Keep the original Canva design so you can return to those objects later.
To export, choose Share, Download and PDF.
Use the digital preset for screen reading or print for printing.
Some menus show these as PDF Standard and PDF Print.
Leave flattened PDF off when you want to retain separate PDF content where supported.
Here's the part many tutorials skip.
Leaving a PDF unflattened does not create boxes that recipients can click and type into.
A rectangle labeled Name is still just artwork until a PDF form field is added.
For a fillable file, open the exported PDF in a form editor such as Acrobat Pro.
Choose all tools, prepare a form, select your file and create the form.
Review the detected fields and add any missing text fields or checkboxes.
Preview the form, type a test response and save it.
Re-open the save file in a PDF reader to confirm the field's work.
Keep the Canva source for layout changes and the completed form PDF for people to fill in.
