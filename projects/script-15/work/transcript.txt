This tutorial shows you how to create a reusable email template in Canva and export it as HTML for an email platform.
From the Canva homepage, click Create and search for email.
Choose the email design type and start with a suitable layout.
Use this dedicated format so you can work with email content blocks and HTML export.
Replace the header with your logo and business name.
Add a clear headline, a short introduction and an image that supports the message.
Build the body with text and image blocks.
Keep the structure simple using a single main column for this example.
Add a button and set its link to the page you want readers to visit.
Update the footer with your contact details.
Leave clearly labeled spaces for anything you're sending platform adds,
such as an unsubscribe link, and configure those details in that platform before sending.
Keep a master copy with placeholder headings and images.
Duplicate it whenever you need a new campaign so the original template stays reusable.
Use Preview to check the desktop and mobile layouts.
Send a test email to your Canva login address and check the button.
Image placement and text on your phone.
Here's the part many tutorials skip.
Use Canva's email design type when you need an HTML email.
A regular graphic exported as one long image does not give you the same editable email structure.
Open Share and choose Copy HTML if your email platform accepts pasted code.
Otherwise, choose Download and select HTML and images to export a zip package.
Import the result using your platform's HTML workflow.
Send another test from the actual sending platform
because email clients can display layouts differently.
Your template is now ready to reuse.
