This tutorial shows you how to improve a Canva website's mobile layout,
so visitors can read and navigate it on a phone.
Open the website design and select Preview.
Open the mobile preview so you can inspect the narrow screen layout while editing.
Go to the website publishing settings and check that Resize on Mobile is enabled.
Canva uses responsive reflow to rearrange content for smaller screens,
including stacking items that sit next to each other on desktop.
Return to the design and fix the problem areas one at a time.
Shorten very long headings and narrow wide text boxes.
Keep important content within the page boundaries
and leave enough room between separate elements.
Select objects that need to remain together,
such as a small icon and its label, and choose Group.
Check the mobile preview again after each change.
Avoid grouping the entire desktop layout into one huge block.
Keep related items together while allowing independent sections to rearrange.
Replace oversized decorative elements with simpler ones when they crowd the phone layout.
Make buttons easy to tap and leave space between nearby links.
Check that a large image does not push the main action far down the page.
Here's the part many tutorials skip.
The mobile preview is an approximation.
The published results can vary with the browser and screen width,
so open the live site on your actual phone after publishing the update.
Scroll through every section, tap each button,
and check for cropped text or sideways overflow.
Keep adjusting until the complete page works comfortably on the smaller screen.
