This tutorial shows you how to add an adjustable border around a page in Canva without covering the content.
Open your design and go to Elements.
Under Shapes, add a basic rectangle.
Resize the rectangle so it sits slightly inside all four page edges.
Leave a clear margin between the border and the text, especially if you plan to print the design.
With the rectangle selected, open its Fill Color control and choose the Transparent or No Color option.
Then open Stroke Style in the toolbar, choose a solid line and adjust the line weight.
Choose the border color using the Stroke Color control.
Keep the line thin for a clean document or increase the weight for a stronger frame.
Open Position and centre the rectangle horizontally and vertically.
Check that the spacing around the page looks even.
Lock the border when you are happy with it so it stays in place while you edit the content.
For a decorative version, search Elements for Rectangle Border or Page Border and choose a graphic you can resize to fit.
Some decorative graphics have fewer editing controls than a basic shape.
Here's the part many tutorials skip.
Lowering the transparency of the entire rectangle also fades its outline.
Remove the Fill using the Fill control so the border remains fully visible.
If you need the same border on several pages, duplicate the bordered page before adding the next page's content
or copy the border to your existing pages.
Download a preview and check that the complete outline is visible on every side.
