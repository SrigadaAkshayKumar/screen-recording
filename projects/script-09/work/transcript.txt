This tutorial shows you how to remove several photo backgrounds at once using Canva's bulk background remover.
Start from the Canva homepage and open Projects.
Create a folder for the photos you want to process, then upload your images into that folder.
Use a small test batch first.
Product photos with clear edges and a background that contrasts with the subject are a useful starting point.
Return to the folder listing, hover over the folder and open its three-dot menu.
Select Remove Background.
Canva processes the supported uploaded photos and creates a separate folder containing the edited versions.
The new folder name includes edited, while the original folder stays available.
Open the edited folder and check each cutout.
Look closely around hair, transparent objects, thin straps and any area that blends into the original background.
If you only want certain photos, open the original folder, tick their selection boxes and choose BG Remover from the toolbar at the bottom.
This selected photo method adds the edited copies to the same folder, so check which versions you are opening before placing them into a design.
Here's the important limit.
Bulk background removal handles up to 50 uploaded images at a time and requires an eligible paid plan.
Canva library photos or complete designs inside the folder are not processed like uploaded photos.
If the folder option is unavailable, reduce the folder to 50 images or fewer and check your plan access.
Use the finished cutouts in a new design or download the processed images as transparent PNGs.
