This tutorial shows you how to build a Canva website with several sections that visitors scroll through on one page.
From Canva's homepage, choose a website template or create a blank website design.
Starting with the website format gives you the correct web layout and publishing tools.
Build the top section with a clear heading, a short introduction and one main action, such as a contact button.
Replace the template images and colours with your own content.
At the bottom of the design, click Add section.
Use this second section for an introduction, services or a featured project.
Continue adding sections for the remaining information.
Keep the spacing, fonts and button styles consistent.
A simple structure could be introduction, about, services, examples and contact.
Select your button or text and use the link control to add its destination.
Test each link rather than leaving the template's original links in place.
Open Preview and inspect the desktop and mobile layouts.
Check the order of the content, the text size and whether images or buttons overlap.
Here's the part many tutorials skip.
Add section and Add page do different jobs in the current website editor.
Sections build the scrollable content within one page.
Adding another page creates another website page.
For this tutorial, keep your content inside a single page with multiple sections.
Before publishing, open the dropdown beside Publish and choose Settings.
Review the website address, mobile options and page information.
Choose an available Canva domain or another domain option your account supports.
Click Publish, open the live website and scroll from top to bottom to check the finished result.
