This tutorial shows you how to export a custom icon from Canva as an SVG that stays sharp when resized.
Open the icon design.
For a clean example, use an icon you created from simple shapes or an original vector file you uploaded.
Keep only the artwork you want in the export.
Remove extra text, photographs and background objects, then centre the icon on a page with suitable padding.
Click Share and choose Download.
Open File Type and select SVG.
SVG downloading requires an eligible plan, so check the upgrade indicator if the option is locked.
Enable transparent background if offered, select the icons page and click Download.
Open the saved SVG in a browser and zoom in.
Its vector shapes should remain sharp.
You can also open it in a vector editor to inspect the paths and check whether the result suits your project.
Here's the part many tutorials skip.
Saving a blurry PNG inside an SVG file does not automatically trace it into clean vector paths.
Start with vector artwork when you need an icon that can scale substantially.
If your design contains several icons on one page,
move each icon into its own small design or page before exporting.
Otherwise the SVG can include the whole surrounding layout.
Canva may also restrict downloading an unmodified premium stock element by itself.
Use your own original artwork for this workflow,
rather than treating SVG export as a way to extract stock assets.
Finally, test the icon on both light and dark backgrounds
to make sure its colours and transparent areas look correct.
