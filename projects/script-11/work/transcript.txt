This tutorial shows you how to turn a Google Sheets table into multiple Canva designs using a CSV file.
In Google Sheets, create clearly named columns such as Name, Offer and Website.
Put one complete designs information on each row.
For this example, add three rows with different business names and offers.
Keep the headings in the first row and remove empty rows inside the table.
Choose File, Download and Comma Separated Values to save the current sheet as a CSV file.
Open your Canva template and add a separate text box for each changing field.
Leave logos and other shared decorations unconnected if they should stay identical.
Open Apps and select Bulk Create.
Choose Upload Data, select your CSV and continue.
Use Match and Fill fields if offered, then inspect the matches.
Select a text box, choose Match Data and connect it to the correct column.
Repeat for the remaining fields.
For example, the business name text box should use Name while the promotional sentence should use Offer.
Preview the results and check the longest entries for awkward wrapping.
Adjust the template before generating the batch.
Open the creation options and choose one design with multiple pages if you want all versions together.
Then create the designs and open the result.
Here's the important limitation.
A downloaded CSV is a snapshot.
Editing the Google Sheet later does not automatically refresh this generated batch.
Download a new CSV and regenerate when your data changes.
Bulk Create also requires a supported Canva plan on desktop.
