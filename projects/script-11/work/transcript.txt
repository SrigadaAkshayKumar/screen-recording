This tutorial shows you how to upload a custom font into Canva and use it in your designs.
First, download the font file to your computer.
Canva supports OTF, TTF and WOF files.
If the download is a zip archive, extract it so you can access the actual font files.
Custom font uploads require an eligible Canva plan and permission to manage the brand kit's fonts.
If you only want a font already included in Canva,
select your text and search for it directly in the font menu.
To upload your own, return to Canva's homepage and select Brand.
Choose the correct brand kit if your account has more than one.
Go to Fonts, open the Add control and choose Upload a font.
Select the font file, click Open and confirm that you have the rights needed to upload and use it.
Wait for the upload to finish.
Open a design and select a text box.
Click the font name in the toolbar, then find the font under Uploaded fonts or search for its name.
Select it to apply it to the text.
Check the letters, numbers and punctuation you will actually use.
A font may not include every language or special character your project needs.
Here's the part many tutorials skip.
Regular, bold and italic can require separate font files.
Upload the matching styles if you want Canva to offer them correctly.
If the download contains a variable font, look for static font files,
because Canva's font upload guidance does not support variable fonts.
If the font is missing, confirm that you uploaded it to the same brand kit you are using in the design.
Your custom font is now available for future projects in that kit.
