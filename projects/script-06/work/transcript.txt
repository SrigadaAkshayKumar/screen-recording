This tutorial shows you how to create a batch of image designs with different photos and text using canvas sheets and bulk create.
This workflow creates variations of a template using existing images.
Start on desktop with a Canva plan that includes bulk create, build one sample design containing an image frame, a heading and any fixed branding.
Use elements then frames to add the photo placeholder.
A regular decorative rectangle is not the same as an image frame.
Next, open a Canva sheet and create columns for the information that should change.
For example, use product name and product photo, put one product in each row and insert its image directly into the photo cell.
Select the filled data range, choose actions, then bulk create and continue.
Choose the sample design you prepared. Review Canva's proposed field connections.
Make sure the name column is assigned to the heading and the photo column is assigned to the frame.
Correct any connection that points to the wrong element.
Generate the batch and open the resulting designs. Check the photos as well as the text.
Double-click an image inside its frame to adjust the crop when the subject is cut off.
Here's the part many tutorials skip. A pasted image URL is not a substitute for an image inserted into a sheet cell.
Use actual images from your uploads or Canva library.
Also, different photo shapes can produce very different crops inside the same frame.
Download the finished designs as PNG or JPG files.
You now have a batch of matching graphics with a different image and message in each version.
