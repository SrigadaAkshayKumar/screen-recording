This tutorial shows you how to handle font changes when importing a PDF into Canva and
how to preserve its appearance when editing the text is unnecessary.
Upload the PDF from Canva's homepage, then open the imported design.
Select the affected text and check the font menu.
If the original font is available, apply it and compare the size, spacing and line breaks
with the PDF.
If the font is missing and your plan and role support font uploads, go to Brand, open
your brand kit and find Fonts.
Choose Add to category, then upload a font.
Upload the licensed font file and wait for it to finish.
Return to the design, select the affected text and choose the font under Uploaded Fonts.
Repeat for the required styles or weights.
Here's the part many tutorials skip.
An editable PDF import cannot guarantee identical fonts and layout.
Adding the font does not automatically repair every text box.
If preserving the page's appearance matters more than editable text, render the original
PDF pages as high resolution PNG images using a PDF tool.
Create Canva pages with the same proportions.
Upload the PNGs and place one image edge to edge on each page.
This image method keeps the rendered lettering but the original text becomes part of the
image.
Add new Canva text above it if needed.
Download a test page and compare it with the original before processing the entire document.
