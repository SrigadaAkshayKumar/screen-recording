This tutorial shows you how to build and publish a simple Canva landing page with one clear action for visitors.
From the homepage, search for a website template and choose a layout that suits your offer.
Start with a simple design so the main message is easy to find.
Replace the first headline with the result you offer.
Under it, add one short sentence explaining who the offer is for, followed by a clear button such as book a call or get the guide.
Select the button, open link and paste the destination, such as your booking page or sign-up form.
If the button contains separate text and a shape, make sure the clickable area works where a visitor is likely to tap.
Add supporting sections below the headline, explain the main benefits, show a useful example or testimonial and answer the question visitors are most likely to have before clicking.
Use add section to extend the same landing page.
Use add page only when you want another webpage with its own address.
Preview the design on desktop and phone.
Check that the headline is readable and the main button is easy to find without scrolling through unrelated material.
Choose publish website and follow the available domain options.
Set an appropriate website title and description, then publish and test the live link.
Here's the part many tutorials skip.
A button labeled sign up does not collect information by itself.
It needs to open a working form, booking system or checkout destination.
Complete that journey yourself so you know the landing page takes visitors all the way to the intended action.
