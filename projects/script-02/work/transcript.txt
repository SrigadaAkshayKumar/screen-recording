This tutorial shows you how to select several files and upload them to Canva together.
Open your Canva design, select Uploads in the left sidebar, and click Upload Files.
In the file picker, open the folder containing your files.
To select separate files on Windows, hold Ctrl while clicking each one.
On a Mac, hold Command instead.
To select a continuous group, click the first file, hold Shift, and click the last file.
To select everything in that folder, press Ctrl and A on Windows, or Command and A on a Mac, while the file list is active.
Click Open.
Canva begins uploading the selected files together.
Keep the editor open until the uploads finish.
Check the images, videos, or audio categories to find the different file types.
Add only the files you need to the current design.
Here's the part many tutorials skip.
Selecting several files for upload does not automatically turn them into separate pages or arrange them in your preferred order.
You still decide where each file goes in the design.
If one file fails, check its format and size, then upload that file again.
You do not need to repeat every successful upload.
For a very large collection, work in smaller groups so it is easier to spot missing files.
You have now uploaded multiple files to Canva in one selection.
