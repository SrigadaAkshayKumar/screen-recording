Script 2, how to add 3D shapes in Canva.
This tutorial shows you how to add actual
rotatable 3D elements to a Canva design.
Open a presentation or a social media design,
then select elements.
Find the 3D category or search for 3D
and browse the available objects.
Choose a simple object such as a sphere or cube
and add it to the page.
Select the object and drag to change its viewing angle.
Then resize it and position it beside your text.
If the toolbar displays color swatches,
click one and choose a color that matches your design.
Some objects have several editable colors
while others keep their original materials.
For a clean example, place a blue sphere
beside a bold heading on a light background.
Keep enough space between the object and the lettering
so the shape supports the message.
You can also generate a custom object.
Open Magic Media, select the 3D tab,
describe the object and choose Generate 3D.
Try a short prompt such as a smooth orange cube
with rounded corners.
Here's the important limitation.
A normal 3D looking graphic is different
from a rotatable 3D element.
If an item only rotates flat on the page,
return to the 3D category.
Canva currently exports these 3D objects as static images.
Interactive rotation is available in supported presentations
and published websites rather than in a downloaded image
or animated 3D export.
Preview your design in its intended format before sharing
and use a clear starting angle that looks good
even when the object is still.
