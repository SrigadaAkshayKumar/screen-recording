This tutorial shows you how to make a simple stickman video in Canva using an animated character and a custom movement path.
Create a video design and choose a plain background.
Open elements and search for stick figure walking or animated stickman.
Preview the results and choose an animated graphic with the movement you need.
If you want a consistent character throughout the video, look for matching graphics from the same creator or collection.
Place the character near the left side of the scene.
Add a simple ground line and an object such as a sign, desk or door on the other side.
Select the stickman, click animate and choose create an animation.
Drag it toward the object, release the mouse and preview the movement.
Adjust the available movement settings until the travel speed looks natural with the character's existing walking cycle.
Add a short text box or speech bubble.
In the timeline, make it appear when the character reaches the object.
Leave enough time for viewers to read the message.
Add another scene on the main track to continue the story.
Reuse the background and choose a matching pose or animation for the next action.
Here's the part many tutorials skip.
A static stickman graphic will slide along a custom path, but its legs will not start walking.
Use an already animated walking graphic for moving limbs.
You can still use static poses for reactions, explanations or simple cutaway scenes.
Preview the scene changes, adjust the text timing and add a voiceover or sound effect if it helps the story.
Download the result as an mp4 video.
