This tutorial explains how to create internal links in a Canva website and check whether
they jump within a page or open another website page.
First, understand the destination.
An anchor link jumps to a location within the same webpage.
A page link opens another page.
Canva's current help instructions document page links, so check the destinations available
in your editor before promising a same page jump.
Select the contact button or its text.
Open link from the floating toolbar, using more if the link icon is hidden.
Under pages in this document, choose your contact page and click done.
Preview the website and test the button.
In Canva's current multi-page website structure, this opens the selected page.
If you only need visitors to reach your contact details, place those details on that page
and use this supported navigation method.
You can also enable navigation menu in the website settings to expose your website page's
automatically.
For an older scrolling website, test the internal link on the published version.
Older designs can organise their content differently, so do not assume a tutorial recorded in another
editor will behave the same way.
Here's the part many tutorials skip.
Typing a hashtag followed by a heading, such as contact, does not create a working anchor
by itself.
The published webpage needs a matching target identifier.
If your editor does not offer your section as a link destination, use page navigation
or a website builder with explicit section anchor controls when a true same page jump
is required.
Publish your changes and test the actual site on desktop and phone.
Confirm where the visitor lands before sharing the link.
