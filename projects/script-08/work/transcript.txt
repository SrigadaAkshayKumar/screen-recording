This tutorial shows you how to bring a recording you already made into Canva and use it in a design.
First, save the actual recording file to your computer.
If it is still on your phone, transfer or download it before starting.
For this example, use an MP3, M4A or WAV recording.
Open your Canva video project, select Uploads and click Upload Files.
Choose the saved recording, click Open and wait for the upload to finish.
Find the file under Audio and add it to the timeline.
Move the track to the point where the recording should begin.
Play the first few seconds.
If there is silence before the speaker starts, select the audio and trim its beginning using the track handle.
Move the trim track back to the intended start time if needed.
Trim any unnecessary silence at the end, then adjust the volume and preview it with your visuals.
Here's the part many tutorials skip.
A voice message link is not the same as a local audio file.
Canva needs a usable recording file for this upload method.
If the recordings format is not accepted, convert the audio to a supported format.
Changing the file name extension does not convert it.
Make the video long enough for the recording, then select Share, Download and MP4 Video.
Your pre-recorded audio is now included in the Canva project.
