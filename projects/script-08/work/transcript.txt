This tutorial shows you how to create a moving image carousel in Canva using duplicated pages and match and move.
Create a presentation or social video design.
Upload three photos and place them side by side.
Make the centre photo larger so it becomes the main focus.
Duplicate the entire page.
On the second page, move the existing photos into new positions so the next photo becomes the larger centre image.
Resize the others to create the same balanced arrangement.
Duplicate that second page and repeat the process for the third photo.
Move the existing image objects on each duplicate rather than deleting and adding new copies.
Between the first two pages, click Add Transition and choose Match and Move.
This is a premium transition so check the crown indicator and your plan access.
Apply it between the second and third pages as well.
Adjust the transition duration and preview the sequence.
Shorten the page holds for a quicker carousel or lengthen them so viewers can inspect each photo.
Here's the part many tutorials skip.
This creates a carousel-style animation inside a video.
Downloading the pages as PNG images produces a static swipe carousel.
For an Instagram carousel with separate animated items, export the required pages or sections as separate supported videos.
For one continuous moving showcase, choose Share, Download and MP4 Video, then include all three pages.
Play the export to check every image change.
