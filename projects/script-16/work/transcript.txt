This tutorial shows you how to update typography across a multi-page Canva design without changing every text box individually.
First, make a copy of the design if you want to compare the new typography with the original.
Select one heading and open the font menu.
Choose the replacement font.
If Canva displays a change all option for that font replacement, use it to update the matching font throughout the design.
Repeat the process for a separate body font when necessary.
Replacing one typeface should not be assumed to replace every different font used in the file.
For a coordinated font combination across pages, click the page background or thumbnail, select edit, and open styles.
Choose a font set, then select apply to all pages.
If your account has brand kit text styles, you can also apply those through the edit panel.
Use apply to all pages to update existing text across the design using the configured heading and body styles.
Here's the part many tutorials skip.
Changing a font changes the width and height of the letters.
Even when the font size stays the same, a heading can wrap onto another line or extend beyond its text box.
Inspect the longest headings, narrow text boxes, and slides with dense paragraphs.
Adjust the box width, font size, or spacing where necessary while keeping the hierarchy consistent.
Text that is baked into an uploaded image will not change with the editable text.
Replace that image or recreate its lettering if it needs the new typeface.
Preview the complete design and check a downloaded sample before sharing the updated version.
