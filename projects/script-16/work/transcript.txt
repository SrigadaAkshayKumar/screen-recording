This tutorial shows you how to duplicate a complete video page in an older Canva project
and how to repeat a scene in the current timeline editor.
Open your video and look at the bottom of the editor.
The exact method depends on whether the project uses page thumbnails or the newer multitrack timeline.
In a page-based project, select the page thumbnail you want to duplicate.
Open its three-dot menu and choose Duplicate Page.
Some layouts also show a duplicate icon above the page.
The new page contains the original page's visual layout.
Drag its thumbnail to the required position,
then change the text or replace the footage to create the next scene.
If your project uses the current multitrack editor, work with the timeline elements instead.
Select the clip you want to repeat.
To copy a complete scene, also select the text and graphics that belong to that section.
Open more and choose Duplicate or press Ctrl and D on Windows or Command and D on a Mac.
Place the copied elements after the original section
and check that the overlays line up with the new clip.
Here's the part.
Many tutorials skip.
Duplicating only the background clip in the new timeline
does not include every text box, graphic or separate audio track above it.
Select the elements you need, then check their copied timing individually.
In either editor, preview the join between the original and the copy.
Check for repeated narration, overlapping music or a transition that now needs adjusting.
You can now reuse the scene's layout while changing only the content that should be different.
