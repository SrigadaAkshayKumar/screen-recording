This tutorial shows you how to convert one image, or several images, into a PDF using Canva on your computer.
Start a design using the page size you need, choose A4 for a standard document,
or use custom size if the PDF should match a particular image or print size.
Open uploads, click upload files, and select your JPG or PNG images.
Drag the first image onto the blank page. Resize it using a corner handle.
Keep the whole image visible if you want to preserve its edges.
Setting a differently shaped image as a full page background can crop part of it, so check the result carefully.
For several images in one PDF, add a new page for each image.
Place the next image on that page and repeat until every image has its own page.
Open grid view and drag the pages into the correct order.
Delete any empty pages and check that each image is sharp enough to read at its intended size.
Click share, then download.
Open file type and choose PDF standard for a document you will view or send online.
Choose PDF print when you need a print focused export.
Under select pages, include every page you want in the PDF.
Click download, then open the saved file and check the page count and image orientation.
Here's the part many tutorials skip.
Placing a photo of text inside a PDF does not guarantee searchable or selectable text.
If you need to copy the words from a scanned document, use an OCR tool to recognize them.
Your images are now combined into one PDF with one image on each page.
