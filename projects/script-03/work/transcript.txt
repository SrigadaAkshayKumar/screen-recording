This tutorial shows you how to upload a folder from your computer to Canva.
Open a Canva design and select Uploads from the left sidebar.
Open the menu beside Upload Files and choose Upload Folder.
In the folder picker, select the folder you want to upload, then confirm the selection.
If your browser asks for permission to upload the files in that folder, confirm the upload.
Wait for Canva to finish processing the contents.
Check that the files you need have uploaded successfully.
Return to Canva's homepage and open Projects to find your uploaded folder.
Open it to inspect the contents, then use the media in your designs.
Here's the part many tutorials skip.
Folder uploads are a desktop workflow.
Canva's mobile app does not currently provide the same folder upload option.
Use a computer for this method.
Also, uploading a zip file is different from uploading a folder.
A stored zip does not automatically unpack into media you can use in your design.
Extract it on your computer first, then select the extracted folder.
If a folder contains many files or some files fail,
try a smaller folder containing only the media you need.
Check any failed files individually rather than assuming everything uploaded.
Your folder's uploaded contents are now available in Canva.
