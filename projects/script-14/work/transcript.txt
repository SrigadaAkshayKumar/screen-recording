This tutorial shows you how to create your own movement path for an element in Canva.
Open a video, presentation or social design and add the object you want to animate.
For this example, use an arrow from Elements.
Place the arrow where its movement should begin.
Select it, click Animate and choose Create an Animation.
Click and drag the arrow across the canvas to draw its movement path,
then release the mouse button.
Canva records the route and uses it to animate the object.
Start with a short, simple route.
Once that works, try a gentle curve or a change of direction.
Preview the path before adding extra effects.
Use the movement style controls to adjust how the recorded movement behaves.
Change the speed with the available slider.
If you want an arrow or vehicle to turn along its route,
enable the option that orients the element to the path.
Click Done to save the animation.
To rebuild it, return to the settings, choose Delete Path and draw a new route.
Here's the part many tutorials skip.
This tool records a movement path for the object.
Drawing a complicated route does not create separately editable keyframes
for every property such as opacity, size or colour.
Keep the object inside the canvas unless you deliberately want it to enter or leave the frame.
