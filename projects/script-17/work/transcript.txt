This tutorial shows you how to make a bar chart race with Canva's built-in chart tools.
Open a design and choose charts from the side panel.
If you do not see it, open Apps and find charts there.
Under Bar Race Charts, choose a bar race chart or single colour bar race.
Select the inserted chart and click Edit to open its data controls.
Replace the sample data with your own labels and values, keeping the sample table structure as a guide.
Include values for more than one time period, so the chart has changes to animate.
For a larger dataset, use import data and upload a supported spreadsheet file.
Check the data in Canva before styling the chart.
In Chart Setup, assign the category labels and the values for the time periods.
Use colour by if you want an additional grouping to control the colours.
Open Customize to add a clear title, choose the maximum number of visible bars, and adjust playback speed and looping.
Preview the animation and compare its first and last periods with your table.
Here's the part many tutorials skip.
An ordinary bar chart with an entrance animation does not become a chart race.
A race uses a time series, so the bar lengths and rankings can change as time advances.
For this example, use monthly totals consistently.
Do not mix monthly values with cumulative totals halfway through the dataset,
because that changes what the comparison means.
Present or share the chart in a format that preserves its playback.
A PNG or printed PDF is static, so test your chosen delivery format before using it for the finished animation.
