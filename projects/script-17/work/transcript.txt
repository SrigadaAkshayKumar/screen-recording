This tutorial shows you how to bring a chat GPT-generated image into Canva and use magic layers to edit individual parts when the image is suitable.
Save the generated image from chat GPT to your computer.
Use the downloaded PNG or JPG so you retain the available image detail.
Open a Canva design, select Uploads and upload the image.
Add it to the page and keep a duplicate page containing the original so you can compare the result.
Select the image, click Edit in the toolbar and choose Magic Layers.
Wait while Canva processes the image and rebuilds it as separate design elements.
Click a recovered text element to change its wording, font, size or colour.
Select a graphic to move or resize it.
Remove an unwanted element and replace it with your own image or a Canva graphic if needed.
For a poster, try correcting the headline, moving the main illustration and adding your logo.
Check the spacing again after each change. Here's the part many tutorials skip.
Magic Layers reconstructs an editable design from the image.
Inspect the spelling, object boundaries and background because complex details may separate imperfectly.
Graphic layouts and illustrations generally work better than realistic photographs.
If you want to replace an object in a photographic image, select the photo, open Edit and choose Magic Edit when available.
Brush over the object, describe the replacement and generate a result.
