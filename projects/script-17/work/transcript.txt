This tutorial shows you how to organize Canva folders so your designs and media are easier to find.
From the Home page, Open Projects, then All Projects.
Select Add New, choose New Folder, enter a name and click Create Folder.
For a tutorial channel, you could create one main folder for each app, such as Canva, CapCut and ClipChamp.
Open the Canva folder and create a few useful subfolders, such as thumbnails, source images and finished designs.
Keep the structure simple enough that every file has an obvious destination.
Return to Projects and select the designs or media you want to organize using the thumbnail checkboxes.
Choose Move, select the destination folder and confirm.
You can also open a folder, choose Add New, then Upload Files and upload new assets straight into that folder.
Here's the part many tutorials skip.
Remove from Folder and Move to Trash have different results.
Removing an item from a folder leaves the file in Canva.
Moving it to Trash is the deletion action.
Use descriptive folder names and keep related source files near the designs that use them.
For shared work, check folder access before assuming a teammate can open its contents.
Open each folder and check that the correct items are inside it.
Your Canva files now have a clear folder structure you can reuse for future projects.
