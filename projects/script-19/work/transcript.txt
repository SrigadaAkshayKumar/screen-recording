This tutorial shows you how to export a Canva presentation to PowerPoint and preserve the look of its animation using a video workaround.
First, open the presentation in Canva. Select Share, Download and Microsoft PowerPoint.
Choose the slides you need and download the PPTX file.
If the option is not in download, look for Microsoft PowerPoint under Share, See All.
Open the file in PowerPoint and check the fonts, images and layout.
Correct any differences before presenting.
Here's the part many tutorials skip.
Canva's PPTX export does not currently preserve its animations and embedded videos as working PowerPoint effects.
There is no export checkbox that transfers all of that motion into editable PowerPoint animations.
To keep the animation visible, return to Canva and download the animated slide as MP4 video.
Export one slide at a time if you want to control when each slide advances in PowerPoint.
In desktop PowerPoint, open the matching slide and choose Insert, Video, This Device.
On a Mac, use the equivalent video from file option.
Select the MP4 and insert it as an embedded video.
Resize the video to cover the slide.
Open playback and set, start to automatically if you want it to begin when that slide appears.
Repeat this for the other animated slides and test the presentation in slideshow view.
The animation is now playing as video, so its text and objects cannot be edited separately inside that video.
If you need editable objects with click-by-click effects, use the PPTX export and rebuild those effects in PowerPoint's Animations tab.
Save the finished presentation and test it on the computer you will present from.
