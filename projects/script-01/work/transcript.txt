This tutorial shows you how to build a simple 2D animation in Canva using graphics, custom movement, and text.
From Canva's homepage, create a landscape video design.
Open elements and choose a background, a character, and one or two objects for your scene.
Keep the illustration styles similar so everything looks like it belongs together.
Arrange the background first, select it and lock it so you do not move it accidentally while working on the character.
Select the character and click animate in the toolbar.
Choose create an animation, then drag the character along the route you want it to follow.
For example, move it from the left side of the scene toward a house on the right.
Release the mouse, preview the movement, adjust the available movement settings, and click done.
A short smooth route is easier to control than a long path with several sudden turns.
Add a text box for the character's message, give it a simple entrance animation,
then use its bar in the video timeline to make the text appear after the character arrives.
To continue the story, add another scene using the plus button on the main timeline track.
Reuse the same background and character, but change the position, message, or action.
Here's the part many tutorials skip.
Moving a character along a path does not automatically animate its arms and legs.
For a walking character, choose an already animated graphic,
then use the custom path to move that animation across the scene.
Preview the complete sequence, then use share, download, and mp4 video to save your animation.
