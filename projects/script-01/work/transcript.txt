This tutorial shows you how to export a Canva design as a WebP image directly from the download menu.
Open the design you want to export and check its dimensions.
For a website banner, use dimensions that suit the space where the image will appear
instead of exporting a much larger image than you need.
Click Share in the upper right corner, then choose Download.
Open the File Type menu and select WebP.
Canva now supports WebP downloads, so an external converter is not normally necessary.
This file type is useful for website images because it supports compression and transparency.
Choose the page you want to save.
Adjust the export size if that control is available on your plan,
then choose a quality setting.
Start with a higher quality version when your design contains small lettering or thin lines.
For an image without a solid page background,
enable Transparent Background if your plan includes it.
Remove any full page background image or rectangle that would otherwise cover the transparent area.
Click Download and open the saved image.
Check the edges of the lettering and compare its file size with your original export.
Here's the part many tutorials skip.
WebP export is not available for Canva docs.
If the option is missing in a doc, place the content into a regular design,
such as a custom size graphic, and open the download menu there.
Also remember that renaming a PNG file with a WebP extension does not convert it.
Select WebP before downloading so Canva creates the correct file.
Your design is now saved as a WebP image, ready to upload to a compatible website or app.
