This tutorial shows you how to turn a table of questions into a quiz video in Canva,
with time to guess before each answer appears.
On Canva Desktop, create a blank 16 by 9 presentation.
Each page will become one question in the finished video.
Bulk Create requires an eligible plan, such as Canva Pro.
Build your first page with a background, a question text box,
three separate answer choices, and another text box for the correct answer.
Label the choices A, B, and C so viewers can follow along.
Select the page thumbnail, click the clock icon for edit timing,
and set the page to 10 seconds.
Select the correct answer text box, right-click, and choose Show Element Timing.
Drag its timing handles so it appears at 7 seconds and stays until the end.
Keep the question and choices visible throughout the page.
Open Apps, search for Bulk Create, and open Canva's tool.
Choose Bulk Create, then Enter Data Manually.
Clear the sample table and add columns called Question,
Choice A, Choice B, Choice C, and Answer.
Enter one quiz question per row, then click Done.
Select Match and Fill Fields.
Review the connections carefully.
To correct one, select the relevant text box,
choose Match Data, and connect it to the right column.
The answer reveal box must use the Answer column.
Preview the data to check for missing answers and questions
that overflow their text boxes.
Open the More Options menu beside Create Designs.
Under Output, choose one design with multiple pages,
then create the designs and open the result.
Here's the part many tutorials skip.
The Bulk Create preview does not play video timing.
Play the generated design and confirm that the first two answers
actually remain hidden for 7 seconds.
Correct their element timing if necessary before continuing.
Finally, choose Share, Download, and MP4 Video.
Select all quiz pages and download.
Watch the exported file to check every question, answer, and pause.
