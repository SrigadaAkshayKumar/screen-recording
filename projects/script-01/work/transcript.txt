This tutorial shows you how to upload your own files to Canva and add them to a design.
Open the design you want to work on.
In the left sidebar, select Uploads, then click Upload Files.
Find the file on your computer, select it, and click Open.
Wait for the upload to finish before trying to use it.
Your uploaded media appears in the Uploads panel.
Find it under the appropriate category, such as images, videos, or audio.
Click an image to place it on the page or add a video or audio file to your video timeline.
You can also open File Explorer or Finder and drag a file directly into the Uploads panel.
This is useful when the folder is already open beside Canva.
Here's the part many tutorials skip.
Uploading a file and placing it in a design are separate actions.
A completed upload does not mean the file has automatically been added to your page or timeline.
For a PDF you want to edit as a document, upload it from Canva's homepage
and open the imported design after processing finishes.
To find uploaded media later, return to the homepage, open Projects, and look in Uploads.
You can reuse the same media in another design without uploading it again.
Your file is now uploaded and ready to use in Canva.
