This tutorial shows you how to create an editable table in Canva and format it for a schedule,
price list or comparison.
Open your design and select elements from the left sidebar.
Find the tables category and click a table to place it on the page.
Double click inside the first cell and type your heading.
Continue filling the other cells.
For this example, use three columns called Service, Details and Price.
To add another row, select the table, open its three-dot menu and choose Add Row.
Use Add Column when you need an extra column.
The menus beside individual rows and above columns also let you move or delete them.
Drag a column divider to give longer descriptions, more space.
Open the table menu and use size columns equally if you want matching widths.
Select the header cells and change their fill colour using the colour tile in the top toolbar.
Make the heading text bold and choose a contrasting text colour.
Select border to change which grid lines are visible, then adjust their colour and thickness.
Here's the part many tutorials skip.
Do not shrink the entire table just to make one long description fit.
Widen that column or shorten the description first so the other cells stay readable.
On desktop, you can also copy a small range of cells from a spreadsheet and paste it into a Canva table.
Check the result before copying a large dataset.
Click Share, choose Download and select PDF Print for a printed table or PNG for an image.
Keep the Canva design so you can update the original cells later.
