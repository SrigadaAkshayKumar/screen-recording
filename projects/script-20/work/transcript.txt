This tutorial shows you how to troubleshoot a video that will not upload or finish processing in Canva.
First, open the video on your computer.
Play several parts, including the ending, to check that the file is complete and readable.
If it will not play locally, obtain a working copy before uploading again.
Check the file's size and format.
Canva's current video upload limit is 1 GB per file and MP4 is one of its supported formats.
Compress or shorten a larger file before retrying.
If the format seems compatible but Canva rejects it, try exporting a fresh MP4 copy from your video editor.
Changing the file name extension alone does not convert the video.
Open the Canva design and upload through uploads, then upload files.
Wait for processing to finish before placing the clip or generating captions.
Here's the part many tutorials skip.
A supported file extension does not guarantee that an incomplete or unusually encoded file will upload.
A small, freshly exported test clip helps you separate a file problem from a browser or connection problem.
Try a stable connection and an updated browser.
If necessary, test another browser and check Canva's status page for an upload incident.
Also check whether your account has available storage.
If a small test video uploads but the original still fails,
investigate that original file's size and encoding before retrying it repeatedly.
