This tutorial shows you how to export a single Canva page without downloading the rest of the design.
Open the design and go to the page you want to save.
Note its page number so you can check it against the download selection.
Click Share, choose Download and select the file type you need.
Use PNG or JPG for a still image, PDF for a document page or MP4 for a page containing animation or video.
Open the page selection control.
Choose this page to export the page currently in view.
If your menu shows a checklist instead, deselect all pages and tick only the one you want.
You can also choose Custom and select the required page there.
Confirm that only one page is included, then click Download.
Open the save file and verify its content.
A single page PDF should contain one page, while an image export should show only the chosen artwork.
Here's the part many tutorials skip.
Selecting a page thumbnail in the editor does not always change the download menu from all pages.
Check the export selection itself before clicking Download.
For an animated page, inspect its duration and audio before exporting.
A still image format will show a static result,
even if the page contains moving elements in Canva.
If you are editing a newer video design with one continuous timeline,
there may be no separate pages to select.
This page selection method applies to designs that actually contain pages,
such as presentations and multi-page graphics.
You can now save the page you need while keeping the full original design available for later edits.
