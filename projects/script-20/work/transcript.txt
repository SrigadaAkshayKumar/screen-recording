This tutorial shows you how to create a paperback cover in Canva using Amazon KDP's exact cover dimensions.
Finalise the book's trim size, interior type, paper and page count first.
These details determine the cover size, especially the spine width.
Open KDP's print cover calculator and templates page.
Enter the book specifications, calculate the dimensions and download the template.
Extract the download so you can access the PNG guide.
In Canva, choose custom size, select inches and enter the full cover width and height supplied by KDP.
Use the measurements for the entire wrap, including its bleed.
Upload the PNG template.
Stretch it to match the canvas exactly, reduce its transparency and lock it as a guide.
Keep it above your background while checking the layout.
For a left-to-right paperback, the back cover is on the left, the spine is in the middle and the front cover is on the right.
Build the artwork over the guide.
Add the title and author name to the front, a description to the back and a continuous background across the full wrap.
Keep text inside the template's safe areas and leave its barcode area clear if KDP will add the barcode.
Add spine text only when the book qualifies and it fits inside the template's spine guides.
KDP requires at least 79 pages for paperback spine text.
Here's the part many tutorials skip.
The calculator template already includes bleed.
Adding Canva's crop marks and bleed during download changes the file size and can cause a mismatch.
Unlock and delete the template guide before exporting.
Choose share, download and PDF print.
Leave crop marks and bleed unchecked.
Use flattened PDF if available as KDP recommends flattened cover files.
