This tutorial shows you how to crop and size a photo in Canva for a passport style application or print.
First, read the photo requirements for the specific passport or application.
Dimensions, head size, background and editing rules vary.
For this demonstration, we will use a 35 by 45 millimetre layout.
But enter the measurements your application actually requires.
On Canva's homepage, create a custom size design.
Change the units to millimetres.
Enter the width and height and create the design.
Open uploads and add a sharp recent portrait taken against an acceptable plain background.
Use the application rules when choosing the expression, lighting and framing.
Add the photo to the design and enlarge it until it fills the page.
Double click it to adjust the crop.
Keep the face centred and use the required head measurement and clear space above the head as your guide.
Avoid stretching the image because that changes facial proportions.
Adjust the crop using the original aspect ratio instead.
Here's the part many tutorials skip.
Matching the outside dimensions does not automatically make a passport photo acceptable.
The face size and composition must also satisfy the issuing authority
and some applications restrict digital background replacement or retouching.
For printing, download PDF print without crop marks or bleed.
Print at actual size or 100%, then measure the result with a ruler.
Turn off fit to page because it can change the dimensions.
For a digital application, follow its separate pixel dimensions,
file format and file size limits when exporting.
Check those requirements before submitting the photo.
