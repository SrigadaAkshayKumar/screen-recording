This tutorial shows you how to add a scannable QR code to a Canva design.
First, open the destination page in your browser and copy its full address.
Use the page people should reach directly, such as a menu, booking page or portfolio.
Open your Canva design.
Select elements and search for QR code.
In Canva's QR code options, choose Create Static for a fixed destination
or Create Dynamic if you need to update the destination later.
For this example, choose Create Static.
Paste your address into the URL field, adjust the foreground and background colours if needed
and select Save to add the code.
Place it where people can easily notice it.
Use a dark code on a light background and leave a clear border around it.
Add a short instruction nearby, such as scan to book.
For print, keep the code at least two centimetres wide
and increase it when people will scan from farther away.
Avoid stretching it into a rectangle.
Here's the part many tutorials skip.
The destination of a static QR code cannot be changed inside Canva after creation.
If you generate it with the wrong address, create a replacement code before printing.
Choose a dynamic code from the beginning when the link needs to change later.
Download the design in the format you need,
then scan the exported code with your phone.
For printed material, scan a physical proof as well.
Confirm that the correct page opens and works for someone who is not signed into your account.
Your QR code is now ready to share.
