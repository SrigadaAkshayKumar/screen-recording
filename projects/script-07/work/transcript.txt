This tutorial shows you how to make sentences appear one after another in a Canva video.
Create a video design and open the text panel.
Add your first sentence, then create a separate text box for each additional sentence.
For this example, use three short lines.
Set the font, size and alignment before animating them.
Leave enough space between the sentences so the layout stays readable as each line appears.
Select the first text box and open animate.
Choose fade, rise or another text entrance.
Apply the same style to the second and third text boxes for a consistent result.
Now use the video timeline to stagger the sentences.
Let the first text box begin at zero seconds, the second at about one and a half seconds
and the third at about three seconds.
Extend their right edges to the same ending time if you want all three sentences to remain visible together.
Shorten each box's visible span when the next sentence should replace it.
Play the video and check that each sentence stays on screen long enough to read comfortably.
Slow the sequence down when the wording is longer.
Here's the part many tutorials skip.
Line breaks inside one text box do not give every sentence its own independent timeline layer.
Separate text boxes let you control the sentences individually.
For a live presentation, use appear on click and click order instead of fixed video timing.
Download the timed video as mp4 video when finished.
