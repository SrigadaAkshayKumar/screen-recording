This tutorial shows you how to upload a collection of images to Canva without selecting them one at a time.
First, gather the images into one folder.
Give them recognisable file names, such as thumbnail01, thumbnail02 and thumbnail03, so missing files are easier to identify later.
Open Canva, enter a design and select Uploads.
Click Upload Files and open the folder containing your images.
Click inside the file list, then press Control and A on Windows or Command and A on a Mac to select all the files.
If the folder contains other file types, select only the images you need instead.
Click Open and let Canva complete the uploads.
You can also select the images in File Explorer or Finder and drag the selection into Canva's Uploads panel.
Once uploading finishes, inspect the image thumbnails and compare them with your source collection.
Upload only the missing images if anything failed.
Here's the part many tutorials skip. Bulk uploading does not mean bulk placement.
The images become available in your account, but Canva does not automatically build a finished design with one image on every page.
For a large collection, upload smaller batches and verify each batch before continuing.
This makes errors easier to isolate.
You can now add the uploaded images to pages, frames or future designs whenever you need them.
