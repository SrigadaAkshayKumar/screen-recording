This tutorial shows you how to download several Canva video designs together and explains
the separate option for exporting individual pages as videos.
For multiple designs, open Projects and select the designs you want using their selection
checkboxes.
Open the Selections Available actions, choose Download and select MP4 as the file type.
Bulk downloading requires a supported page or organisation plan.
Canva currently allows up to 25 designs in one MP4 or GIF batch, so use smaller batches if
you have more.
Start the download and extract the .zep file.
Check the file names and open the exported videos to confirm that the correct designs
were included.
If your videos are separate pages inside one presentation, open that design instead.
Go to Share, then Download, choose MP4 Video and enable Download Pages as separate files
when the option is available.
This page-based method is useful for a batch of short clips where each page is meant to
become its own video.
Here's the part many tutorials skip.
Canva's updated video design type uses a continuous timeline.
It does not offer page-by-page video export in the same way as a multi-page presentation.
Create a separate design for each finished video when you need independent files from
that workflow.
Also check Music and VoiceOver in the separate exports.
A sequence that sounded correct as one long design may need different audio when each page
stands alone.
Run a small batch first, verify the results, then download the remaining videos using
the same settings.
