This tutorial shows you how to clear the animations throughout a Canva presentation.
Open the presentation and start with the first slide.
Click an empty area, open animate and use remove animation in the page tab to clear its page effect.
Next, select the animated text boxes, images and shapes on that slide.
Open their animation settings and remove the effects from those objects as well.
You can try selecting several objects together to remove their animation in one operation.
If the group selection does not provide the removal control, select the objects individually.
Unlock any locked animated objects before editing them.
Continue through the slide thumbnails and repeat these checks on every page.
This clears both page level and independently assigned object animations.
Now, inspect the transitions between slides.
Click each existing transition and remove it from its settings.
Run the presentation from the first slide to confirm that changes between pages are plain cuts.
Here's the part many tutorials skip.
Clearing a page, animation does not guarantee that separately animated text, custom paths
or moving media are static.
An uploaded video or GIF can still play after Canva's animation effects have been removed.
Replace moving assets with still versions when necessary.
Also check any text that was configured to appear on click if you want all content visible immediately.
Preview the entire presentation once more.
Every slide is now checked for page animations, object movement and transitions.
