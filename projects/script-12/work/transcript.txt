This tutorial shows you how to add a live events calendar to a Canva website using a calendar embed link from Calgette.
Open your website design in Canva and create a section for upcoming events.
Leave a wide clear area where the calendar will appear.
In another browser tab, sign in to Calgette and create a calendar.
Add a sample event with its title, date, time and location.
This external calendar will supply the live event information.
Open Calgette's embeddable calendar area and select your calendar.
Choose a view such as month or schedule and adjust the colour to suit your website.
Click Get Embed Code, select the direct link tab and copy the link.
Use this dedicated calendar link for the embed.
Return to Canva, open Apps and search for embeds.
Paste the calendar's direct link and click Add to Design.
Resize the calendar to fit your events section.
Give it enough height to display the event list or month grid without feeling cramped.
Add a short heading above it so visitors understand what they are looking at.
Here's the part many tutorials skip.
An embed link and HTML iframe code are different things.
Canva's embeds workflow takes a supported URL.
Pasting the iframe code itself will not create this calendar.
Preview the website on desktop and mobile, then publish or republish it.
Open the published address and click the sample event to check the details.
Finally, update that event in Calgette and reload the website.
Confirm that the change appears.
You now have a live calendar rather than a static calendar image.
