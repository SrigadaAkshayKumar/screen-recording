This tutorial shows you how to create an invitation website in Canva with event details, a location link, and an RSVP button.
From Canva's homepage, search for a wedding website or event website template.
Choose a website design that matches your event, then open it in the editor.
Replace the main title with the event name.
Add the date, start time, venue, dress code, and any information guests need before attending.
Delete template sections you will not use.
Upload your own photo or replace the template's image.
Keep the text easy to read against the background and use short sections so guests can find the details quickly.
Add a button or a clear text link called View Location.
Select it, open the link control, and paste the venue's map link.
For RSVPs, prepare a response form in your preferred form service and copy its published response link.
Add an RSVP button in Canva and attach that link.
Include a deadline beside the button if you need responses by a particular date.
Use Preview to check the desktop and mobile layouts.
Make sure the buttons open the correct destinations and that none of the text overlaps.
Click Publish Website, choose an available free Canva site address or another domain option supported by your account.
Review the website settings, enable resize on mobile, and complete the publish steps.
Here's the part many tutorials skip.
Guests need the published website address.
Open that address in a private browser window and test it before sending invitations.
Confirm that your RSVP form also accepts responses from your guests.
If you change the event details later, republish the website so visitors see the update at the same address.
